# 学習ノート

発表や進捗報告ごとに `YYYY-MM-DD_<内容>/` を作り、その回に向けて学んだことを Markdown で書く（例: `notes/2026-10-09_progress/`）。日付は発表・報告の日にして、[slides](../slides/README.md) のディレクトリ名とそろえる。

- 資料から書いたところには、出典をキーとページで付けておく（例: `[hohenberg1964inhomogeneous, p.B865]`）。キーは [references](../references/README.md) の `references.bib` のもの。卒論を書くときに、どこから引いたかをすぐたどれる。
- 式は `$...$`・`$$...$$` で LaTeX の記法で書く。GitHub や VS Code のプレビューで表示され、Marp のスライドや LaTeX の原稿にもそのまま貼れる。
- 計算・実験の結果は `experiments/<名前>/README.md` に書き、ノートからはリンクする。
- 疑問点・質問したいことは、ノートの最後にまとめておく。
- AI に書かせた部分は、自分で書いた部分と区別がつくようにしておく（見出しを分ける、注記を入れるなど）。
